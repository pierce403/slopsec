# Repository Instructions

- Commit and push after every completed website update.
- In this workspace, use `git --git-dir=.slopsec.git --work-tree=.` if the read-only placeholder `.git` directory prevents normal `git` commands.
- Before committing, run the relevant local checks for the files changed. For this static site, validate the HTML/CSS enough to catch broken references and preview-card regressions.
- Keep `main` publishable. If a change is not ready to deploy, do not leave it uncommitted on `main`.
- Preserve the old-school terminal aesthetic: black base, phosphor green text, monospace typography, and direct copy.
- The site is for slopsec.org, an AI-focused infosec research and consulting thinktank.
- The tagline is: `sketchy shit, non-deterministic prices`.
